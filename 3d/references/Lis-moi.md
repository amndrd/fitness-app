# Tes références

Dépose ici les images de machines et de designs que tu aimes : captures, photos, liens.

- Range-les comme tu veux. Un dossier par machine aide (par exemple `chest-press/`, `butterfly/`, `disques/`).
- Si tu as le lien d'une image, colle-le dans un fichier texte à côté : on saura d'où elle vient.
- Je les regarde avant de modéliser chaque machine et je les cite sur les planches.

Les images restent sur ton Mac : elles ne partent pas sur GitHub (voir `.gitignore`).
